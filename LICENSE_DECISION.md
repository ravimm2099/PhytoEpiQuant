# Choose a license before publishing

No license has been selected on behalf of the author. A public GitHub repository is not automatically open-source.

For an open-source R Shiny project, consider **MIT** (permissive) or **GPL-3.0-or-later** (copyleft). Select one after checking institute policies, dependencies and third-party dataset/figure rights, then add its full text as `LICENSE`.

The published example dataset and logo may have separate attribution/permission requirements.
