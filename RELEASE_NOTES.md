# PhytoEpiQuant v1.0.0

First consolidated public-release candidate, based on the scientific v1.5 code.

- Merges previous phases and iterative releases into one Shiny application.
- Dataset diagnostic planner is second in the navigation.
- Preserves simulations, probability and spatial analysis, Venn overlap and threshold forecasting.
- Includes original-scale DPC fitting, AIC/AICc and residual diagnostics, chronological holdout, replicate-level AUDPC and exploratory factorial ANOVA.
- Includes example datasets, dictionaries, published benchmark and regression tests.
- Adds repository documentation, citation metadata, GitHub CI and release packaging.

**Release gate:** Run GitHub Actions and test `shiny::runApp('.')` locally before tagging as a verified public release. Add a license after author/institution approval.
