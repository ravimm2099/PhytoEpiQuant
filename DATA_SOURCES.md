# Data provenance

## Published reference dataset

`examples/PowderyMildew_published.csv` is a teaching and validation dataset based on the `epifitter` R package's powdery mildew example, with standardized columns for PhytoEpiQuant.

- Alves, K. S., & Del Ponte, E. M. (2021). *Analysis and simulation of plant disease progress curves in R: Introducing the epifitter package*. Phytopathology Research, 3, 22. https://doi.org/10.1186/s42483-021-00098-7
- epifitter OSF repository: https://osf.io/xkfym/ (DOI: 10.17605/OSF.IO/XKFYM)

Check upstream data license and attribution before redistribution. The OSF project metadata's CC0 declaration is not necessarily a license for every included source file.

## Other examples

Other `examples/*.csv` files are synthetic educational data; they should not be presented as independent field observations.
